# 我的博客

基于 GitHub Pages 的个人静态博客，访问地址：<https://qq5203344.github.io>

## 文件结构

```
.
├── index.html          # 首页
├── about.html          # 关于页
├── css/
│   └── style.css       # 全站样式
└── posts/
    ├── hello-world.html
    └── getting-started.html
```

## 如何写新文章

1. 在 `posts/` 下复制一篇现有文章，改名（如 `my-post.html`）。
2. 修改标题、日期和正文。
3. 在 `index.html` 的文章列表里加一个新的卡片块。
4. 推送到 `main` 分支，GitHub Pages 自动部署。

## 技术栈

- 纯 HTML + CSS，无构建工具
- 托管于 GitHub Pages
- 响应式设计，支持移动端
